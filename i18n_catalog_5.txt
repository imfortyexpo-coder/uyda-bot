<blockquote expandable>Файлы (Excel, PDF, Word, фото) передаются через бота и хранятся у партии. Просто пришлите файл боту — он спросит, к какой партии его отнести и кому отправить: 🛃 Специалисту по таможне, 🧾 1С УНФ-Оператору, 👔 Директору (можно нескольким сразу). Или на карточке партии: «📎 Документы» → «📤 Отправить файлы». Подпись к файлу станет комментарием.\nПолучатель получает сам файл и нажимает «✅ Принято» — отправителю приходит ответ. Кто не принял файл больше суток — получает напоминание утром. У партии видна вся история: кто, кому, когда, кто принял; любой файл можно получить снова, реестр — в Excel. Копии файлов хранятся в папке docs рядом с ботом.</blockquote> ¦ <blockquote expandable>Fayllar (Excel, PDF, Word, rasm) bot orqali uzatiladi va yukda saqlanadi. Faylni botga yuboring — u qaysi yukka biriktirish va kimga yuborishni so‘raydi: 🛃 bojxona mutaxassisiga, 🧾 1C UNF operatoriga, 👔 direktorga (bir nechtasiga birdaniga ham mumkin). Yoki yuk kartochkasida: «📎 Hujjatlar» → «📤 Fayllarni yuborish». Faylga yozilgan izoh sharh sifatida saqlanadi.\nOluvchi faylning o‘zini oladi va «✅ Qabul qilindi» ni bosadi — yuboruvchiga javob keladi. Faylni bir kundan ortiq qabul qilmagan kishiga ertalab eslatma keladi. Yukda butun tarix ko‘rinadi: kim, kimga, qachon, kim qabul qildi; istalgan faylni qayta olish mumkin, reyestr — Excelda. Fayllar nusxasi bot yonidagi docs papkasida saqlanadi.</blockquote> ¦ <blockquote expandable>Files (Excel, PDF, Word, photos) are passed through the bot and kept with the shipment. Just send a file to the bot — it will ask which shipment it belongs to and whom to send it to: 🛃 the customs specialist, 🧾 the 1C UNF Operator, 👔 the Director (several at once is fine). Or on the shipment card: «📎 Documents» → «📤 Send files». A file caption becomes the comment.\nThe recipient gets the file itself and taps «✅ Accepted» — the sender gets a reply. Anyone who has not accepted a file for more than a day gets a reminder in the morning. The shipment shows the full history: who, to whom, when, who accepted; any file can be received again, the register is in Excel. Copies of the files are kept in the docs folder next to the bot.</blockquote>
