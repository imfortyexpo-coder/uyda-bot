# UYDA Импорт — Telegram-бот GOLD DISHES

Приватный репозиторий: код бота @Uyda_import_bot (учёт импортных партий, документы, риски, дашборд).

**Здесь только код.** Токен (`env`), база (`bot.db`), копии базы (`backups/`), файлы партий (`docs/`)
и таблица импорта в GitHub не попадают — это закреплено в `.gitignore`.

## Обновить бота на ноутбуке
1. В окне бота — Ctrl+C.
2. Двойной щелчок по `update.bat`.
3. `start.bat`, затем /start в Telegram.

## Если что-то сломалось после обновления
`update.bat` показывает, какая версия была до обновления. Вернуть её:
`git reset --hard <номер версии>` в папке бота (или напишите Claude).

Версии — в `CHANGELOG.md`.
