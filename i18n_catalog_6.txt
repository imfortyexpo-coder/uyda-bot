# Обновление 14 · этапы документов, доступы, дашборд
<b>📎 Документы партии</b> ¦ <b>📎 Yuk hujjatlari</b> ¦ <b>📎 Shipment documents</b>
<blockquote expandable>Файлы (Excel, PDF, Word, фото) передаются через бота и хранятся у партии. Просто пришлите файл боту — он спросит, к какой партии его отнести и кому отправить: 🛃 Специалисту по таможне, 🧾 1С УНФ-Оператору, 👔 Директору (можно нескольким сразу). Или на карточке партии: «📎 Документы» → «📤 Отправить файлы». Подпись к файлу станет комментарием.\n🟡 Рабочая версия — для работы между Специалистом по таможне и Оператором, Директору не уходит. ✅ Финальная версия — файл готов: Директор получает его сразу. Отметить готовым можно при отправке или потом кнопкой «⭐ Сделать финальным». Файл с тем же названием — новая версия (v2, v3).\nПолучатель получает сам файл и нажимает «✅ Принято» — отправителю приходит ответ. Кто не принял файл больше суток — получает напоминание утром. У партии видна вся история и фильтры: все, финальные, рабочие, мне, от меня; любой файл можно получить снова, все файлы — одним архивом, реестр — в Excel. Копии файлов хранятся в папке docs рядом с ботом.</blockquote> ¦ <blockquote expandable>Fayllar (Excel, PDF, Word, rasm) bot orqali uzatiladi va yukda saqlanadi. Faylni botga yuboring — u qaysi yukka biriktirish va kimga yuborishni so‘raydi: 🛃 bojxona mutaxassisiga, 🧾 1C UNF operatoriga, 👔 direktorga (bir nechtasiga birdaniga ham mumkin). Yoki yuk kartochkasida: «📎 Hujjatlar» → «📤 Fayllarni yuborish». Faylga yozilgan izoh sharh sifatida saqlanadi.\n🟡 Ishchi versiya — bojxona mutaxassisi va operator o‘rtasidagi ish uchun, direktorga bormaydi. ✅ Yakuniy versiya — fayl tayyor: direktor uni darhol oladi. Tayyor deb yuborishda yoki keyin «⭐ Yakuniy qilish» tugmasi bilan belgilash mumkin. Xuddi shu nomdagi fayl — yangi versiya (v2, v3).\nOluvchi faylning o‘zini oladi va «✅ Qabul qilindi» ni bosadi — yuboruvchiga javob keladi. Faylni bir kundan ortiq qabul qilmagan kishiga ertalab eslatma keladi. Yukda butun tarix va filtrlar bor: hammasi, yakuniy, ishchi, menga, mendan; istalgan faylni qayta olish mumkin, barcha fayllar — bitta arxivda, reyestr — Excelda. Fayllar nusxasi bot yonidagi docs papkasida saqlanadi.</blockquote> ¦ <blockquote expandable>Files (Excel, PDF, Word, photos) are passed through the bot and kept with the shipment. Just send a file to the bot — it will ask which shipment it belongs to and whom to send it to: 🛃 the customs specialist, 🧾 the 1C UNF Operator, 👔 the Director (several at once is fine). Or on the shipment card: «📎 Documents» → «📤 Send files». A file caption becomes the comment.\n🟡 Working version — for work between the customs specialist and the Operator, it does not go to the Director. ✅ Final version — the file is ready: the Director gets it right away. Mark it final when sending or later with «⭐ Mark as final». A file with the same name is a new version (v2, v3).\nThe recipient gets the file itself and taps «✅ Accepted» — the sender gets a reply. Anyone who has not accepted a file for more than a day gets a reminder in the morning. The shipment shows the full history and filters: all, final, working, to me, from me; any file can be received again, all files — in one archive, the register — in Excel. Copies of the files are kept in the docs folder next to the bot.</blockquote>
<b>📊 Дашборд и 🔐 доступы</b> ¦ <b>📊 Dashbord va 🔐 ruxsatlar</b> ¦ <b>📊 Dashboard and 🔐 access</b>
<blockquote expandable>«📊 Дашборд» — бот присылает файл-страницу: главные цифры, завод и расходы по месяцам, расходы к заводу, категории, открытые партии с поиском и сортировкой, риски, документы. Открывается в браузере, интернет не нужен.\nГенеральный Директор в «👥 Команда» → человек → «🔐 Доступы» включает и выключает разделы: документы, рабочие файлы, дашборд, риски, выгрузки Excel, недельный отчёт. Без галочки кнопки раздела не видны.</blockquote> ¦ <blockquote expandable>«📊 Dashbord» — bot sahifa-fayl yuboradi: asosiy raqamlar, oylar bo‘yicha zavod va xarajatlar, xarajatlarning zavodga nisbati, toifalar, qidiruv va saralash bilan ochiq yuklar, xavflar, hujjatlar. Brauzerda ochiladi, internet kerak emas.\nBosh direktor «👥 Jamoa» → odam → «🔐 Ruxsatlar» da bo‘limlarni yoqadi va o‘chiradi: hujjatlar, ishchi fayllar, dashbord, xavflar, Excel yuklamalari, haftalik hisobot. Belgisiz bo‘lim tugmalari ko‘rinmaydi.</blockquote> ¦ <blockquote expandable>«📊 Dashboard» — the bot sends a page file: key figures, factory and costs by month, costs vs factory, categories, open shipments with search and sorting, risks, documents. It opens in a browser, no internet needed.\nThe General Director in «👥 Team» → person → «🔐 Access» turns sections on and off: documents, working files, dashboard, risks, Excel exports, weekly report. Without a tick the section buttons are hidden.</blockquote>
